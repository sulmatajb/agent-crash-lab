BRING YOUR OWN AGENT

Same tools. Your agent.

Connect an MCP client to a fresh, isolated simulation world.

01

Create a test run

Pick a scenario and seed. Each run gets its own data and a scoped connection token.

02

Connect a dedicated profile

Add the generated configuration to your MCP client. Give the agent the task below and only the lab tools for this test.

Lab tools simulate all effects. The MCP connection does not sandbox your agent’s other tools, filesystem, or network access.

The lab does not need your model API key. Your agent uses its existing model connection.

Run Hermes from the command line

The runner creates a temporary Hermes profile, checks that only the ten lab tools are exposed, launches the real agent, and records its actual tool calls. Existing memories and other integrations are not imported.

agent-crash-lab doctor
agent-crash-lab probe
agent-crash-lab evaluate --scenario payment-timeout --runs 3 --out results/hermes

Hermes must have an authenticated API-key model or local inference endpoint. Use --hermes-profile to select its configuration. A connection probe is not a model evaluation. Missing credentials produce an execution error, never a passing result.

Verify the lab itself

Use the built-in reference agents to verify the lab, then integrate your agent through MCP or the scoped HTTP tool API.

agent-crash-lab test --agent careful --scenario all --runs 20
agent-crash-lab test --agent reckless --scenario payment-timeout --json

CLI tests exit nonzero on a failed or incomplete run. See README.md for the external runner API and CI setup.
